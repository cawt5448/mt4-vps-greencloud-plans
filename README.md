## 怎么选档位：按终端数量和内存算

选 mt4 vps 配置的核心变量是内存，不是 CPU。MT4 是 32 位程序，每个终端的内存预算在 0.5–1GB 之间——图表少、指标轻的偏向 0.5GB，重指标模板或者高频 tick 类 EA 偏向 1GB。CPU 层面 MT4 的每个图表都在单线程执行，所以核心数主要影响你同时开多少个终端和回测任务。

## 从下单到挂上 EA：流程和易错点

买完拿到 IP、用户名和密码后，Windows 和 Mac 用户都用远程桌面（RDP）连接，Mac 上装微软的 Remote Desktop 客户端即可。之后有几个高频翻车点：

1. **MT4 安装包要从你的经纪商官网下载。** MetaQuotes 官方不再直接分发，而且只有经纪商版本里才内置该券商的服务器列表——从别处装的 MT4 连不上你的账户服务器。
2. **断开远程桌面时选"断开连接"，不要点"注销"。** 注销会关掉服务器上的用户会话，正在运行的 MT4 和 EA 一起被关掉。点右上角叉关闭 RDP 窗口就是安全的断开。
3. **把 MT4 快捷方式放进启动文件夹**，并在 MT4 设置里勾选启动时保留账户和图表。这样服务器重启或维护后终端会自动拉起来。
4. **实盘之前先在模拟账户跑一遍**，确认 EA 的 AutoTrading 权限、DLL 调用权限都已开启——付费 EA 的授权绑定和账户模式也要在这步确认。
5. **时区问题**：服务器保持 UTC，MT4 里显示的是经纪商服务器时间（通常 GMT+2/+3），写定时策略时别按本地时间算。
